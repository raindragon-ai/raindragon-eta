Before you start: what RainDragon ETA sends

When you send a message on claude.ai, RainDragon ETA sends the conversation's text to RainDragon (inference.raindragon.ai). RainDragon's model predicts how long Claude's reply will be, and RainDragon keeps the text to improve that model. Secret-looking strings such as API keys are removed before it is stored. Nothing is sent while you type.
